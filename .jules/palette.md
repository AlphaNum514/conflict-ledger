## 2023-10-27 - Range Input Accessibility\n**Learning:** In custom UI implementations, structural hints placed adjacent to range inputs are not automatically announced by screen readers without explicit ARIA associations.\n**Action:** Always link contextual helper text to inputs using `aria-describedby`, and ensure semantic `<label for="...">` tags replace structural generic spans (e.g., `<span class="slider-name">`) to improve form control accessibility.
