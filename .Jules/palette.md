## 2024-11-08 - Use semantic `<label>` tags
**Learning:** Replaced `<div>` tags acting as labels with semantic `<label>` tags and `for` attributes for sliders. This significantly improves accessibility by natively linking labels with their corresponding inputs.
**Action:** Use native semantic HTML tags like `<label>` instead of `<div class="label">` whenever associating descriptive text with form inputs.
