## 2024-10-28 - [Accessible Glossary Buttons]
**Learning:** Found that the glossary items in the research edition were using `<div>` elements for interaction (`gl-trigger`), which is inaccessible to keyboard navigation and screen readers as they lack semantic meaning and standard focus behavior.
**Action:** Replaced the `div` element with a `button` element for the glossary trigger. Added `aria-expanded` attributes. Updated the CSS to make the `button` appear visually identical to the `div` by clearing default button styles (`background: none; border: none; font-family: inherit; font-size: inherit; width: 100%; text-align: left; border-bottom: 2px solid transparent;`) and ensuring it spans the full width of the container. Added a `:focus-visible` state to ensure the button receives a clear red outline for keyboard users, making it fully accessible while retaining the original visual design.
